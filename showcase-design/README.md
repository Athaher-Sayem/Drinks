# After Hours — standalone cocktail-search design concept

Open `index.html` directly or run `python -m http.server 8000` in this folder. This is a frontend-only exploration inspired by the original `Index.html` and `utility.js` on starting `main` commit `3b540630`. The original project calls TheCocktailDB for drink search and details, and has a cart. This showcase deliberately uses **four labeled illustrative local sample entries**, no remote fetches, no prices, and a tasting tray rather than pretending to be a working checkout. The saved selections exist only in this open page.

Design direction: expressive after-dark cocktail menu; plum, peach, cream and mint; Fraunces display + DM Sans body + Space Mono labels. Original CSS and JS are untouched. The CSS-created hero illustration and card compositions are conceptual artwork, not downloaded cocktail photos.

Screenshots: `assets/screenshots/desktop.png`, `assets/screenshots/tablet.png`, `assets/screenshots/mobile.png` are rendered full-page captures.
